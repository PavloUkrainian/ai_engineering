Biometric Engineering Standard: 1:1 Facial Verification Performance Metrics

Type: technical_guide Date: 2022-08-30

1. False Match Rate (FMR) vs False Non-Match Rate (FNMR)

For banking KYC compliance, the 1:1 facial matching algorithm must achieve a False Match Rate (FMR) <= 0.001% (1 in 100,000) at an operational False Non-Match Rate (FNMR) <= 1.0%. The similarity threshold corresponding to this operating point must be calibrated on demographic datasets representing the target population.

2. Environmental Normalization

Prior to vector embedding extraction (512-dimensional ArcFace/CosFace embeddings), the input face is aligned via 5-point affine transformation based on eye pupil and mouth corner coordinates, followed by histogram equalization to mitigate harsh lighting variations.
