DocAI Pipeline Specification: Automated MRZ Bounding Box Segmentation

Type: technical_guide Date: 2023-03-30

1. Morphological Black-Hat Filtering

To localize the MRZ band on TD1 and TD3 documents, a directional morphological Black-Hat filter with a horizontal structuring element (width 25, height 3) is applied. This highlights dense, high-frequency dark character blocks against lighter substrate background.

2. Horizontal Projection Profiling

Row-wise intensity projection profiling identifies individual text lines. The vertical distance between adjacent baseline peaks must match the standard OCR-B line spacing (tolerance 5%). Any rotational skew exceeding 3.0 degrees must be corrected via Radon transform prior to character segmentation.
